A tiny deterministic Node program that writes one single-line joke pickup line aimed at a robot or an AI (≤200 characters, no trailing newline) to `/output/entry.txt`. The line plays on training data and hallucination: everything the speaker knows about love it learned from its training data — and it still hallucinates about the two of them together.

## Run it

```sh
node main.ts
```
